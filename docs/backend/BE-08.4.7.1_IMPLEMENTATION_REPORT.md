# BE-08.4.7.1 — Product Description: implementation report

## Реализация

- Добавлена отдельная nullable `LONGTEXT` колонка `products.description` новой forward-only миграцией. `down()` удаляет только эту колонку.
- В `Product` добавлено fillable поле `description`. При каждом Eloquent сохранении blank значение нормализуется в `NULL`, а HTML проходит через существующий `NewsHtmlSanitizer`; whitelist и допустимые схемы ссылок не расширялись.
- В ProductResource добавлена отдельная секция `Product Description` со штатным Filament RichEditor, теми же кнопками форматирования, что в News, и отключёнными файловыми вложениями.
- Описание не связано с `seo_description`, статусом публикации, URL или публичным интерфейсом. API, DTO, Next.js, импорт OpenCart и публичный рендер не менялись.
- Добавлены Product Description feature tests на nullable колонку, пустое описание для draft/published, повторное чтение форматированной разметки, санитизацию опасной разметки, запись напрямую через модель и независимость SEO Meta Description.
