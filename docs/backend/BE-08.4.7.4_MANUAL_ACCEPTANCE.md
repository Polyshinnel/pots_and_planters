# BE-08.4.7.4 — ручная приёмка Filament

Статус: ожидает проверки владельцем. Автоматические тесты не являются ручной приёмкой.

Войдите в Filament → Catalogue → Products и используйте существующие тестовые/рабочие справочники. Не создавайте фиктивные опубликованные товары в рабочем каталоге.

- [ ] Создать Draft без категорий и Primary Category; сохранить и переоткрыть. Убедиться, что Product ID стабилен.
- [ ] Создать Published с выбранными Category и Primary Category; проверить обязательные атрибуты, положительную AED price и Brand/SKU uniqueness.
- [ ] Ввести Description с абзацем, заголовком, списком, bold/italic и ссылкой; сохранить, переоткрыть, затем очистить. Проверить, что SEO Meta Description остаётся самостоятельным.
- [ ] На круглой геометрии выбрать optional Diameter/Height, включая выбранное пустое поле; сохранить и переоткрыть. Повторить с Length/Width/Height для другой геометрии.
- [ ] Для text, number, boolean, select и multiselect проверить значения; включить `false`, `0`, `0.123456` и ранее выбранную inactive option. Убедиться, что заполненное optional нельзя снять без очистки и отдельного сохранения.
- [ ] Проверить Card Display: доступны только применимые и выбранные Attributes; повторно выбрать один нельзя; изменить порядок и переоткрыть запись.
- [ ] Проверить Short Label и numeric unit (`cm` и одну используемую custom unit); убедиться, что precision сохранена, пустые значения не создают лишних разделителей, а текст preview безопасно экранируется.
- [ ] Проверить Live Preview при изменении Name, SKU, price, typed values, selected option и порядка. Убедиться, что nullable price отображается как `Price on enquiry`.
- [ ] Проверить отсутствие изображения, загрузку временного изображения на Create и ready main image на Edit. Preview не должен выдавать неподготовленное изображение за готовое.
- [ ] На Create добавить несколько изображений, выбрать main, задать ALT. На Edit изменить порядок, main и ALT; detach shared asset; проверить pending/failed status и Retry. Вызвать ошибку прикрепления на Create только безопасным способом и подтвердить persistent notification и восстановление через Edit.
- [ ] Проверить SEO Search Preview, SEO overrides, OG override/fallback и canonical URL с Primary Category. Переименовать slug/category только в тестовой записи и проверить сохранение истории URL; авто SEO и HTTP redirects не входят в эту приёмку.
- [ ] Сравнить preview с текущими ProductCard/ProductCardDetails по квадрату изображения, SKU, имени, строке спецификаций, цене/Price on enquiry и ссылочному тексту. Зафиксировать видимые отличия между Filament и Next.js, не требуя пиксельного совпадения.

Автоматически проверены: CRUD и persistence, Product ID/slug/URL history, category/primary rules, SKU/price validation, Description sanitization и независимость SEO description, optional/required assignments и typed values, decimal/false/zero, Card Display order, gallery attach/reorder/main/detach/retry/status/private originals, OG ready fallback, category filters. Требуют браузера/владельца: фактическая реактивность preview, визуальная композиция, RichEditor usability, Filament upload UX и реальное восстановление после ошибки Create upload.
