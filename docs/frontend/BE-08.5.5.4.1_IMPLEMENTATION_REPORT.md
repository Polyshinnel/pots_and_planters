## Реализация

- Добавлен `frontend/src/lib/enquiry/store-v2.ts` с отдельным ключом `potsandplanters.enquiry.v2`, envelope version 2 и строками `{ productId: UUID, quantity }`.
- Реализованы UUID и quantity validation, строгие парсеры v1/v2, v2 serialization, операции add/remove/setQuantity и typed failures. V2 ограничен 100 строками и quantity 1..999999; UUID deduplication сохраняет порядок, одинаковые SKU не участвуют.
- Состояние различает `not_hydrated`, `ready`, `legacy_present`, `corrupt`, `storage_unavailable`, а также persistent и диагностические флаги для v1/v2.
- Legacy v1 читается как отдельный массив исходных unresolved записей. Дубликаты в v1 сохраняются, ID (включая UUID-подобный) не преобразуются. Парсер не объединяет legacy lines и не сопоставляет товары.
- V1 key никогда не записывается/удаляется. Запись v2 проходит полную валидацию, единичный `setItem`, read-back и повторную проверку. Ошибка записи или несовпадение сохраняет новое состояние текущей вкладки с `persistent=false`; повреждение любого источника блокирует операции записи. Storage events перечитывают обе версии.
- SSR snapshot инертен; доступ к `window.localStorage` происходит только при клиентской hydration/операциях.
