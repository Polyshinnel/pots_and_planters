# BE-08.5.5.5.2 — Implementation Report

**Status:** реализация готова к ручной приёмке; Product/Cart submit не активирован.

## Реализация

- Добавлен `frontend/src/lib/enquiry/submit-v2.ts`: discriminated Product/Cart request DTO, whitelist сериализация, проверки shape и границ контракта Laravel, общие adapter methods для `POST /api/v1/enquiries`, типизированный разбор success/error, requestId, field errors и недоступных Product UUID.
- Успех принимается только для HTTP 200/201 с `data.status=persisted`, UUID `enquiryId` и строковым `notificationStatus`. Network/timeout, malformed protocol, 429 и 5xx не считаются успехом. Notification status не влияет на persistence result.
- Добавлен SHA-256 fingerprint через Web Crypto; Cart item order сохраняется. Browser API используется только при вызове операций, без обращения к `sessionStorage` во время импорта/SSR.
- Добавлен Idempotency Attempt Manager с раздельными Product/Cart slots. Ключ из 24 криптографически случайных байтов и `pending` metadata записываются в `sessionStorage` с read-back проверкой до fetch. Повтор после network/timeout/5xx/429 использует прежний ключ; persisted marker блокирует повторную отправку того же payload. Изменённый payload, конфликт и истёкшая неопределённая попытка требуют отдельного явного действия/разбора.
- В sessionStorage сохраняются только version, kind slots, key, SHA-256 fingerprint, timestamp, status и подтверждённый enquiryId/timestamp. Контактные данные и полный payload отсутствуют.
- Добавлены contract/unit tests `frontend/tests/enquiry-submit-v2.test.cjs` и включены в `npm run test:enquiry`.

ProductEnquiryForm, Cart checkout, пользовательский интерфейс и submit gates не менялись. Новый модуль нигде за пределами своих тестов не импортируется. Существующие Contact/Catalogue adapter и flow не менялись. Laravel и backend gates не менялись. Тестовые запросы используют mocked fetch; реальные заявки не создавались.
