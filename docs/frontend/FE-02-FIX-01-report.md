# FE-02-FIX-01 — отчет о корректировках главной

Дата: 2026-10-18. Область: frontend главной и минимальные изменения общей оболочки.

## Выполнено

- Плавающие WhatsApp и Catalogues остаются едиными кнопками из Layout. По последующему указанию пользователя на `/` они изначально скрыты и плавно появляются при `scrollY >= window.innerHeight` — после прокрутки на одну текущую высоту viewport. При возвращении выше порога скрываются. Старый `IntersectionObserver` и обмен событиями удалены. Пассивный scroll listener объединяет обновления через `requestAnimationFrame`; порог пересчитывается при resize и восстановлении страницы. Переход длится 240 мс; при скрытии отключены pointer events, установлены `inert` и `aria-hidden`. Для внутренних маршрутов кнопки видны сразу. Учитывается `prefers-reduced-motion`.
- Если JavaScript недоступен, быстрые плавающие кнопки главной остаются скрытыми; контактный CTA и ссылка на каталоги в обычном содержимом и навигации остаются доступны.
- На мобильных уточнены размеры и межстрочные интервалы Hero/заголовков/описаний, CTA Hero на узком экране располагаются друг под другом. Уменьшены внутренние отступы карточки товаров для узкой ширины. Основной текст остаётся 16 px, подписи — не менее 12 px.
- Тексты Project Support сформулированы как приглашение обсудить варианты, не как обещание доступной услуги или гарантированной доставки.
- По последующему указанию пользователя восстановлены четыре mock-позиции PP-520–PP-523: в подборке снова восемь товаров. Цены сохранены как `Price on enquiry`.
- По последующему указанию пользователя восстановлены исходные mock-данные компании, контактов и шоурумов в Footer, включая строку FE-01 layout preview. Они временно нужны для разработки.
