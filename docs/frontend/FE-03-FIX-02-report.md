# FE-03-FIX-02 — отчёт

## Что изменено

- `frontend/src/types/home.ts`, `frontend/src/types/catalog.ts`: добавлен типизированный набор характеристик товара: `diameterCm`, `heightCm`, `finish`.
- `frontend/src/data/home.mock.ts`: четыре подтверждённых исторических названия очищены от размера и отделки; эти значения перенесены в структурированные поля.
- `frontend/src/data/catalog.mock.ts`: адаптер каталога передаёт характеристики из исходных mock-записей, не меняя ID, slug, SKU, цену, изображение и существующую привязку к категориям.
- `frontend/src/lib/catalog/format-specifications.ts`: добавлен formatter без разбора названия при рендере. Пустые характеристики не отображаются, пустые части и разделители не создаются.
- `frontend/src/components/catalog/ProductCardDetails.tsx`: общий блок SKU, названия, характеристик, цены и ссылки используется карточками каталога и главной. Сохранены уровни заголовков страниц.
- `frontend/src/components/catalog/CatalogCard.tsx`, `frontend/src/components/home/ProductCard.tsx`, их CSS: добавлена строка характеристик; нижний блок цены и ссылки располагается после контента карточки с `margin-top: auto`, без фиксированной высоты и обрезания текста. Для каталога оставлены две колонки и на ширине 320 px; длинный текст переносится.

## Примеры нормализации

| SKU | Название | Характеристики |
| --- | --- | --- |
| 25526 | Coral Planter | Ø 67 × H 67 cm · Bronze patina |
| 24182 | Magnifico Floor Vase | Ø 35 × H 72 cm · Antique bronze |
| 17310 | Pandora Floor Vase | Ø 50 × H 125 cm · Silver leaf |
| 25530 | Coral Floor Vase | Ø 52 × H 120 cm · Bronze patina |

Для остальных featured-товаров и демонстрационных записей отдельные размеры и отделка не указаны: характеристики не добавлялись. Существующие фильтровые атрибуты mock-каталога не использовались как размер или финиш, поскольку их значения являются иллюстративными.

## Проверки

- `cd frontend && npm run typecheck` — успешно.
- `cd frontend && npm run build` — успешно; Next.js сгенерировал страницы `/`, `/catalogues`, `/shop`, `/shop/[category]`, `/[category]`, `/product/[slug]` и `/search`.
- `git diff --check` — успешно.
- Адаптивность проверена по CSS: каталог сохраняет две колонки начиная с 320 px, карточка и её текстовые блоки не имеют фиксированной высоты/line-clamp, а подвал карточки переносится при нехватке ширины. Отдельный запуск визуального браузерного теста на ширинах 320/375/390 px не выполнялся.

## Оставшиеся вопросы

В текущих mock-данных нет подтверждённых размерных и отделочных параметров для остальных моделей. Их можно заполнить после получения данных каталога; сейчас они корректно остаются без строки характеристик.
